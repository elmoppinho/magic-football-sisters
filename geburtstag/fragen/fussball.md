# Fragenkatalog – Happy Birthday Toni

Fußball-Quiz in drei Schwierigkeitsstufen. Diese Datei kann direkt auf GitHub gelesen und bearbeitet werden.

* **Welt 1 – Bundesliga** (leichter): Vereine, Stadien, Rekorde, Regeln
* **Welt 2 – Tour de France** (mittel): Geschichte, Trikots, Rekorde, Berge, Deutsche, Frauen
* **Welt 3 – Weltmeisterschaft** (schwerer): Geschichte, Finals, Rekorde, Frauen-WM

## So ist eine Frage aufgebaut

```
### Kategorie
Fragetext?

- [ ] falsche Antwort
- [x] richtige Antwort
- [ ] falsche Antwort
- [ ] falsche Antwort

> Kurze Erklärung, die nach dem Antworten erscheint.
```

* Fragen stehen unter **„## Welt 1“**, **„## Welt 2“** oder **„## Welt 3“**.
* Pro Welt dürfen beliebig viele Fragen stehen. Bei jedem Start einer Welt – also auch nach jedem Game Over –
  wählt das Spiel 15 neue Fragen aus, bevorzugt solche, die noch nicht gestellt wurden.
* Die Reihenfolge der Antworten wird im Spiel jedes Mal gemischt.
* Stand der Fakten: Sommer 2025 (Ergebnisse späterer Saisons sind bewusst nicht enthalten).
